# Desktop preview artwork

The sample images come from the Samsung TV store's artwork CDN, linked in the
[Samsung TV app ID reference](https://rs.ltd/apps/remote-control-tv/custom-apps/samsung/)
and [Stremio reference](https://rs.ltd/apps/remote-control-tv/custom-apps/android/).
Product names and artwork belong to their respective owners and identify the
sample apps. These files are used only in the desktop preview; on a TV, TVDeck
uses the installed apps' own icons instead. Store artwork can vary over time and
may not match the version installed on a particular television.

# TVDeck brand assets

Selected concept: **A — blue-violet deck**.

| File | Purpose | Dimensions |

All artwork was generated with the built-in ChatGPT image generator. Its model is managed internally; no model identifier is exposed by the tool. The approved Concept A design is retained. macOS `sips` was used only to export the requested pixel dimensions; the wordmark was scaled proportionally and its transparent canvas margins cropped to 2048 × 640. No local alpha cleanup or color replacement was applied. The generated white mark may include small off-white variations.

`originals/` preserves the native generated files before export sizing. `variants/` contains the other concepts. `PROMPTS.md` records the generation prompts. `validation.json` records dimensions, alpha checks and SHA-256 hashes.

These are source brand files under `assets/brand/`; they are not integrated into the TV app.
